Antes dos fluxos: três coisas diferentes

Pull = estratégia
O seguidor toma a iniciativa de buscar novidades.
Fetch = pedido
“Tenho até a entrada 4. Tem algo novo?” Cada busca é um Fetch.
Push = outra estratégia
O líder enviaria sem esperar um pedido. Não é usado aqui. Responder a um Fetch não é Push.

Atenção: “salvo no log” não significa “confirmado”. A consulta lê somente o banco final comitado.
